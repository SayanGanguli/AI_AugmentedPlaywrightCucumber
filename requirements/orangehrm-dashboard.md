# Test Plan: OrangeHRM Dashboard

## Objective

Verify that the Dashboard is correctly displayed after successful authentication.

## Preconditions

- User has valid credentials.
- User can successfully log in.

## Test Scenarios

### TC-DASH-001: Verify Dashboard

Steps:
1. Navigate to OrangeHRM.
2. Login using valid credentials.
3. Verify Dashboard is displayed.

Expected Result:
- Dashboard page should be displayed.
- Dashboard heading should be visible.
- Main navigation should be available.

### TC-DASH-002: Verify Dashboard Navigation

Steps:
1. Login successfully.
2. Verify the left navigation menu.
3. Verify available menu options.

Expected Result:
- Navigation menu should be visible.
- Expected menu items should be displayed.
