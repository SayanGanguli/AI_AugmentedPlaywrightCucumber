# Planner Prompt: OrangeHRM Login Page

## Objective
Analyze the OrangeHRM login page and produce a test strategy blueprint for automation.

## Target URL
https://opensource-demo.orangehrmlive.com/web/index.php/auth/login

## Instructions for Planner Agent
- Review the login page layout and functionality.
- Identify key user flows (e.g., valid login, invalid login, empty fields).
- Break down flows into high-level scenario descriptions (not Gherkin).
- Document an element map with selectors suitable for Playwright.
- Save the output as a markdown file inside `prompts/planner-prompts/` (e.g., `login.md`).
- Do not generate code or Gherkin syntax — only provide structured scenario descriptions and selectors.
